🤝 仮想金額（知人・身内とのお金のやり取り）

貸した・立て替えた・借りたお金を、支出合計とは別に数えます。＋はあなたが受け取る分、−はあなたが払う分です。

いまの仮想金額

オンにすると、貸した・返したお金は「貸し借り」の欄に＋で、返してもらった・借りたお金は−で入り、支出合計と項目の合計が合います。個人再生などの手続き中の方は、身内とのお金の貸し借りについて担当の弁護士・司法書士に相談しておくと安心です。

🔑 AIの設定（Gemini）

このアプリのAIは、GoogleのGeminiを使います。使う人ごとに、Googleから無料でもらえる「鍵」（APIキー）が必要です。最初に1回だけ設定すれば、あとはそのまま使えます。

鍵のもらい方（3分ほど）
  1. 下のボタンでGoogle AI Studioを開き、ふだん使っているGoogleアカウントでログインします。
  2. はじめての人は、利用規約に同意すると鍵が自動で1つ作られます。表示されない時は「APIキーを作成」（Create API key）を押します。
  3. 鍵の横のコピーボタンを押してコピーします。
  4. この画面に戻り、下の欄に貼り付けて「保存して試す」を押します。

AIに送るのは、読み取る瞬間のレシート・通帳・家計簿の画像と、ふり返りのときの集計だけです。このアプリの運営者には、画像も料金も届きません。通帳など見られたくない部分がある時は、写す範囲を必要な行だけにしてください。

鍵の扱いについて
  • 鍵はこの端末の中にだけ保存し、Google（Gemini）以外には送りません。バックアップのファイルにも入りません。
  • 鍵は暗証番号と同じです。人に見せたり、画面の写真を載せたりしないでください。
  • もれたかもと思ったら、Google AI Studio で鍵を削除して作り直してください。

📱 画面

表の見出しの列と列の境目（｜）を指で左右に動かすと、その両どなりの2列の幅だけが変わります。ほかの列はそのままです。

家計簿とボタンの間の境界線を指で上下に動かすと、広さを自由に変えられます（ボタン・スイッチ・戻る/進むを押すと、ここで選んだ高さに戻ります。アプリを開いたときは、ボタンが全部見える位置から始まります）。右上のスイッチは、ボタンの画面では家計簿を、機能の画面では機能の部分を大きくします。横に広い画面（タブレットなど）では左右に並びます。

📐 家計簿の形と費目（読み込み）

いつも使っている家計簿（ノート・アプリ・Excelなど）のスクリーンショットや写真を読み込むと、AIが同じ形の表を画面に作ります。

📸 撮るときのコツ：真上（正面）から、1ページ全体が入る距離で、明るい場所で。いちばん上の見出し（費目の行）がはっきり写るようにしてください。斜めや遠すぎると読めないことがあります。

ここを長押し／クリックして画像を貼り付け（ボタンが動かないとき）

家計簿をつけたことがない人は、読み込まなくても大丈夫です。よく使う費目の表が最初から入っているので、そのままレシートを撮って始められます。

📥 途中から始めるとき（書いてある金額の取り込み）

今の家計簿にもう書き込んでいる月は、そのページを撮ると書いてある金額をこのアプリに取り込めます（1ページ＝1か月）。取り込む前に、確認して直せます。

🔁 毎月の固定費

家賃・光熱費・スマホ代・サブスクなど、レシートが出ない毎月の支払いを登録すると、その日になったら自動で書き込みます。金額が月ごとに変わるもの（電気代など）は、書き込まれた記録を押して直せます。

💾 バックアップ

記録はこの端末の中だけにあります。スマホをなくしたり機種を変えたりすると消えてしまうので、ときどきファイルに書き出しておきましょう。新しいスマホでそのファイルを読み込めば元に戻ります。
